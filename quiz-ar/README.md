# منصة المسابقات التفاعلية (بالعربية)

## التشغيل
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

- **المعلم:** `/host.html` — يُنشئ المسابقة ويحصل على رمز PIN من 6 أرقام.
- **الطالب:** `/play.html` — يدخل برمز PIN واسمه ويجيب من جهازه.

## ملاحظات
- البيانات (الغرف والنتائج) في الذاكرة، فتختفي عند إعادة تشغيل الخادم.
- الطالب الذي ينقطع اتصاله أثناء المسابقة لا يستعيد نقاطه عند إعادة تحميل الصفحة.
- النقاط: الإجابة الصحيحة تعطي من 500 إلى 1000 نقطة حسب سرعة الإجابة.
- للنشر على الإنترنت استخدم أي استضافة تدعم Node.js ومنافذ WebSocket، واضبط `PORT` عند الحاجة.

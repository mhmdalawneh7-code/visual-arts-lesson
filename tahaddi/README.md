# تحدّي — مسابقات صفية عربية

هذه نسخة الكود المصدري للموقع: واجهة عربية، محرر أسئلة، جلسات PIN، مؤقت ونتائج.

## الرفع إلى GitHub
1. فك ضغط الملف على الكمبيوتر.
2. أنشئ مستودعًا جديدًا على GitHub.
3. اختر Add file ثم Upload files.
4. ارفع الملفات والمجلدات بعد فك الضغط، ثم اختر Commit changes.
5. احتفظ بملف pnpm-lock.yaml ومجلد drizzle الخاص بمخطط قاعدة البيانات.

## مهم: تشغيل الموقع
هذا المشروع ليس صفحة HTML ثابتة، ولا يعمل بكامل خصائصه على GitHub Pages.
يستخدم React وVinext وخادم Cloudflare Workers وقاعدة Cloudflare D1 باسم DB.
رفع الملفات إلى GitHub وحده لا ينشئ موقعًا عاملًا ولا قاعدة بيانات.
يلزم إعداد استضافة متوافقة وربط D1 وتطبيق ملفات SQL في drizzle قبل الاستخدام.
ملف .openai/hosting.json يخص استضافة النسخة الأصلية؛ لا تستخدم هوية مشروعها لنشر مشروع مستقل.

للتطوير: استخدم Node.js 22.13 أو أحدث، ثم ثبّت الاعتماديات بـ pnpm install.
البناء: pnpm build. المعاينة: pnpm dev بعد إعداد ربط DB وتطبيق المخطط محليًا.

## الاستخدام
اختر مسابقة جاهزة أو أنشئ أسئلتك. شارك رمز الجلسة مع الطلاب ثم ابدأ الجولة.
كل إجابة صحيحة تساوي 1000 نقطة. مدة السؤال 30 ثانية، والانتقال يتحكم به المعلم.
احتفظ بصفحة المعلم مفتوحة أثناء الجولة؛ لا تتضمن النسخة الحالية استعادة جلسة المعلم بعد تحديث الصفحة.

## الوصول من جهاز المدرسة
قد تخضع الاستضافة الجديدة أيضًا لمراجعة سياسة الوزارة. تغيير الاستضافة لا يضمن إتاحة الوصول.
